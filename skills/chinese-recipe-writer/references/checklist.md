# Pre-Publish Quality Checklist

## Per-Language Checks (repeat for each of EN/ZH/DE/JA/FR)

- [ ] Title tag includes primary keyword, within length limit
- [ ] Meta description within length limit, contains keyword
- [ ] URL slug is short, clean, contains dish name
- [ ] Only one H1 (article title)
- [ ] H2/H3 hierarchy is logical
- [ ] Story section is engaging with cultural context (especially EN version)
- [ ] Measurement units match target market (EN=US imperial, others=metric)
- [ ] Key condiments have localized purchase suggestions and substitutes
- [ ] Each step is clear, 2-3 sentences max
- [ ] At least 3 images (hero shot, key step, ingredients)
- [ ] All images have localized alt tags
- [ ] Internal links to 2-3 other same-language recipe articles
- [ ] FAQ has 4-6 real questions (user concerns may differ by language)
- [ ] 2-3 affiliate links pointing to correct country's Amazon
- [ ] JSON-LD Recipe structured data present and valid
- [ ] Read through confirms natural language, no machine-translation artifacts
- [ ] Word count is within SEO sweet spot range

## Cross-Language Checks (do once after all versions complete)

- [ ] All 5 language versions produced (ZH/EN/DE/JA/FR)
- [ ] Every page has hreflang tags linking all versions
- [ ] Affiliate links point to correct Amazon per language
- [ ] Measurements localized per language
- [ ] Shopping suggestions reference local stores per country
- [ ] DE version has more detailed/precise step descriptions
- [ ] JA version includes "difference from Japanese-style" talking point
- [ ] FR version includes Chinese-French technique comparisons where natural
- [ ] ZH version is suitable for WeChat/Xiaohongshu direct distribution
- [ ] All versions share the same images (only alt tags differ)

## Content Quality Signals

- [ ] Article provides complete answer to user's search intent
- [ ] No thin content sections (every section adds value)
- [ ] Pro tips show genuine expertise beyond basic instructions
- [ ] FAQ answers are substantive (3+ sentences each)
- [ ] Affiliate recommendations feel natural, not pushy
- [ ] Cultural/historical info is accurate and sourced
